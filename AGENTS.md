# ICON GRAPHICS architecture

This is a React 19 / TypeScript site using TanStack Start file routes, Vite and the Cloudflare Vite plugin. The live custom domain is attached to the existing Cloudflare Worker `icon-graphics-new`; the forms API is a separate Worker at `forms-api.icongraphics.com.ng`. Global styles live in `src/styles.css`; the root shell and base brand metadata live in `src/routes/__root.tsx`. Each public route defines its own title, description, Open Graph metadata and canonical URL. Static public routes are prerendered for crawler and edge-host access. TanStack generates `src/routeTree.gen.ts`; do not edit it manually.

`src/components/MarketingPage.tsx` contains the shared layout, original logo, navigation, footer, WhatsApp integration, portfolio artwork, and page/section components. `EnquiryForm.tsx` posts real multipart enquiries to the Cloudflare forms API Worker. `NotFoundPage.tsx` is the shared missing-page fallback. `src/routes/portfolio_.$projectId.tsx` deliberately opts out of the portfolio list parent and validates project ids in a loader with `notFound()`.

`src/data/site.ts` is the central source of official services, portfolio entries, FAQ content, social links, testimonials and catalogue URL. Keep all nine official service names and descriptions accurate. Use the official brand identity, email and WhatsApp number. Do not invent clients, testimonials, awards, employees, qualifications, pricing or historical achievements. New portfolio items use a service id for category and optional image, video and audio paths in `public/portfolio/`. Preserve concept labels for demonstration work and remove them only when genuine project content replaces it. Keep a preview in every service category while real work is unavailable.

Uploaded source assets are preserved in `public/img/`; never redesign or recolour the original logo or generate a replacement founder portrait. The logo is intentionally displayed against its original black background. Serve supplied client media from `public/portfolio/` and preserve its aspect ratio. External illustrative images may use their direct source URLs. Mockups are code-native illustrative concept art, not completed client projects.

The design uses clean white, charcoal and restrained cyan accents derived from the original multicoloured logo, Manrope headings and DM Sans body type. Alternate light/dark sections, retain generous spacing, and collapse split layouts on mobile. Maintain keyboard focus, labelled form fields, reduced-motion support and honest placeholders. No decorative buttons without actions.

Contact and quote share `project-enquiry`. The form posts multipart data to `https://forms-api.icongraphics.com.ng/`, the dedicated Cloudflare forms Worker. Preserve all named fields, the honeypot, required consent, file type and size validation, timeout and response-status checks. Do not replace real submissions with simulated success. The endpoint's notification configuration is managed on the forms Worker; do not change it without instruction.

Cloudflare Workers and Wrangler handle production routing and deployment. `src/start.ts` applies security headers to server-rendered responses and retains CSRF protection for server functions; `public/_headers` supplies headers for static assets. Do not add a wildcard SPA rewrite. The custom domain is already connected to the existing production Worker; do not change DNS, Worker domains or bindings during ordinary content updates. Update the static sitemap as pages/projects change. Privacy and terms may contain owner-confirmation items.

Use existing dependencies. Keep changes focused and update this document if architecture changes. Read the Cloudflare and TanStack Start guidance relevant to a task before changing runtime configuration. Follow current run instructions on whether local builds/tests/dev servers are permitted. No secrets belong in client code, files or logs.

`src/components/UpgradePages.tsx` owns quotation-based pricing, the Insights index and guides, and refund/cancellation and delivery policies. `src/data/insights.ts` contains ten repository-authored editorial guides (one per insight topic) and topics, without fabricated founder bylines. Each guide has a unique Unsplash thumbnail loaded directly from its source URL, a lead `content` paragraph and optional `paragraphs`/`sections`. All Insights cards share one layout (photo with overlapping category tag, category pill, date, read time, title, 2-line excerpt, "Read the guide"); there is no featured first card. On mobile the category filter scrolls horizontally. Extend the sitemap for new guides. Package tier price fields remain in `src/data/site.ts` as internal reference data; the public pricing UI presents tiers as quoted-to-scope and does not display fixed package prices. Project records support objectives, direction, execution, deliverables and labels for honest case studies.

The enquiry form uses multipart FormData for one optional reference attachment, validated to PDF/JPEG/PNG/WebP under 5 MB, and joins additional service choices into one registered field. Keep all brief fields registered. `src/lib/analytics.ts` emits integration events only; do not add analytics network requests or identifiers without a consent-aware integration. Supplied reference originals remain in `public/img/`; `logo-reference.png` and `rapheal-adebayo-supplied.jpeg` are the current display sources.

Projects may define a `gallery` (src, alt, caption, intrinsic size) of supplied client media in `public/portfolio/`; when present, the case study renders a dark showcase (lead image, HTML5 promo video, supporting image grid) instead of the illustrative `Art` hero. Erin Fashion World uses genuine supplied logo, bag, hang tag and promo video files. Lewa Glam Beauty Empire uses its genuine supplied promotional flyer, social media grid and promo video. Opeyemi Beauty Touch / Collections uses its genuine supplied tri-fold brochure, business card front/back sheet and promo video; a landscape lead image (ratio above 1.3) gets the wide showcase variant and a lone tall supporting image is width-capped. Global Trade Connect uses its genuine supplied pitch deck slides (cover, who we are, vision, services) and promo video; an odd final supporting image in a multi-image grid is centred at half width. Nova Global Brands uses its genuine supplied serum packaging mockup, square digital ad graphic and promo video; all five client case studies now show real media.

On the Services page, each service shows its first real project card. When a service has no supplied project yet (currently photography, video, web, writing and audio), `ServicePreview` in `MarketingPage.tsx` shows a card with the same structure instead. It uses Unsplash stock photography served through the Image CDN, plus code-native mockups: a viewfinder, a video player whose play button plays the real showreel promo, a laptop showing a dark-theme site, an editorial page and an animated waveform that respects reduced motion. Each card is labelled "CONCEPT PREVIEW". Once real work exists for a service, the project card replaces the preview automatically.

The homepage "The ICON GRAPHICS Difference." section (`IconDifference`, after the services overview) is a dark glassmorphism 4-column grid (2 columns on tablet, 1 on mobile) of four fixed points in `DIFFERENCE_POINTS`; it replaced both the former Studio Capabilities grid and the older homepage "Why" block (`Why` is still used on the About page). Portfolio media in `Art` (cards on the homepage, portfolio and services pages) and the case-study showcase use `object-fit: contain` on a `#121212` bordered stage so artwork is never cropped. Case-study promo videos render through `CaseVideo`, a branded video card: the client's own portfolio image (`project.image`, served through the Image CDN at 40% opacity on a `#121212` pink/purple gradient stage) with a glowing play button covers the video (`preload="auto"`, `playsInline`). Clicking it removes the cover, turns on native controls and starts playback, so no poster uploads are needed. "CONCEPT PREVIEW" badges (`.concept-pill`) use a solid `#0a0a0a` background, white text and a thin translucent border so they stay readable on any image. The FAQ renders intro, question list, then the "Still have questions?" WhatsApp contact card (founder photo) in source order, so on mobile the card follows the last question; on desktop (above 768px) grid placement puts the card under the intro in the left column, sticky, while the list spans the right column. Every case study's left column holds a sticky dark glassmorphism "Project summary" card (client, services from the text after `·` in `label` plus the service category, `location`, gradient WhatsApp enquiry button); it becomes static on mobile. The hero ends with a "SCROLL TO EXPLORE" link whose arrow only bounces when reduced motion is off. `LOCATION` in `src/data/site.ts` holds the official headquarters and availability wording, rendered as a stacked `.location-block` (small grey uppercase labels, white values) in the footer and on the contact/quote aside. Use it as-is and never add a street address.
